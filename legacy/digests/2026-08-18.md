# NVIDIA 블로그 요약 — 2026-08-18

### [Developing Nemotron 3.5 Lightning NVFP4 with QAD Using NVIDIA Model Optimizer](https://developer.nvidia.com/blog/developing-nemotron-3-5-lightning-nvfp4-with-qad-using-nvidia-model-optimizer/)

`Nemotron` `NVFP4` `Quantization` `Model Optimizer` `Megatron-LM` `Knowledge Distillation`

> QAD로 Nemotron 3.5 Lightning을 4비트 양자화하며 정확도 손실 대부분을 복구

#### 요약

- Nemotron 3.5 Lightning을 66GB(BF16)에서 22GB(NVFP4)로 압축하면서, 단순 PTQ(학습 후 양자화) 대신 QAD(양자화 인지 증류)를 적용해 정확도 저하를 크게 줄였다.
- QAD는 PTQ로 만든 양자화 모델(student)을 원본 BF16 모델(teacher)이 KL divergence 손실로 지도 학습시키는 2단계 파이프라인이다.
- 공격적으로 양자화한 체크포인트에서 PTQ만으로는 median 정확도 복구율 95~96%였으나, QAD 적용 후 98~99.7%까지 회복됐다.
- NVIDIA Model Optimizer의 launcher(`megatron_lm_qad.yaml`, `mbridge_qad.yaml`)로 PTQ→증류→내보내기 전 과정을 재현 가능하다.

#### 시사점

- 메모리와 처리량 제약이 큰 환경에서도 정확도 손실 없이 더 공격적인 양자화(W4A16, NVFP4 KV 캐시 등)를 선택할 수 있는 실전 레시피를 제공한다.
- Model Optimizer의 오픈소스 QAD 워크플로우를 자신의 모델에 그대로 적용해 최대 4배 처리량 향상과 함께 NVFP4 체크포인트를 만들 수 있다.
- 에이전틱·코딩 벤치마크(Terminal-Bench, SWE-Bench 등)에서 QAD가 PTQ 대비 꾸준히 우수해, 실서비스용 경량 모델 배포 시 품질 저하 위험을 낮춘다.

#### 용어 설명

- **NVFP4**: NVIDIA가 정의한 4비트 부동소수점 양자화 포맷으로 모델 크기와 연산량을 크게 줄인다.
- **PTQ (Post-Training Quantization)**: 이미 학습된 모델의 가중치를 추가 학습 없이 저정밀도로 변환하는 양자화 기법.
- **QAD (Quantization-Aware Distillation)**: 양자화된 모델이 원본 모델의 출력을 모방하도록 재학습시켜 정확도 손실을 보완하는 기법.
- **KL divergence**: 두 확률분포(여기선 teacher와 student의 출력 로짓)의 차이를 측정하는 손실 함수.
- **Mamba**: 어텐션 대신 상태공간모델(SSM) 구조를 사용하는 시퀀스 처리 레이어.
- **KV 캐시**: 트랜스포머 추론 시 재사용을 위해 저장하는 Key/Value 텐서, 양자화 대상이 될 수 있다.
- **Megatron-Bridge**: Hugging Face와 Megatron Core 체크포인트 간 양방향 변환을 지원하는 NeMo 프레임워크 내 PyTorch 네이티브 라이브러리.

#### 상세 내용

**QAD란 무엇인가**

QAD는 원본 고정밀 모델(teacher)을 이용해 양자화된 모델(student)을 가르치는 방식이다.

- 1단계: 전정밀 모델에 PTQ를 적용해 양자화된 student 체크포인트 생성 (W4A16)
- 2단계: student를 시뮬레이션된 양자화를 거치며 순전파시키고, teacher와의 KL divergence 증류 손실로 학습

![Nemotron 3.5 Lightning NVFP4 QAD 프로세스 다이어그램](https://developer-blogs.nvidia.com/wp-content/uploads/2026/08/nvfp4-qad-nemotron-3.5-lightning.webp)
*이미지 출처: [원문](https://developer.nvidia.com/blog/developing-nemotron-3-5-lightning-nvfp4-with-qad-using-nvidia-model-optimizer/)*

**Step 1: PTQ 체크포인트 확보**

- 베이스 모델 NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16이 teacher 역할을 하고, 동일 모델에 PTQ를 적용해 student를 생성한다.
- 5가지 PTQ 레시피(max, mamba_fp8_max, MSE, four_over_six, four_over_six+NVFP4 KV)를 비교했으며, 모두 lm_head를 W4A16으로 양자화하고 attention projection은 BF16 유지, 1,000개 샘플로 단일 DGX B300에서 캘리브레이션했다.
- 가장 공격적인 레시피는 K/V를 NVFP4(W4A4)로 양자화하고 QK^T·attn·V 연산은 BF16 유지.
- QAD로 이후 복구가 가능하므로 PTQ 단계에서는 median 정확도 복구율 95~99%를 목표로 일부러 공격적으로 양자화한다.
- 32K 시퀀스 길이 캘리브레이션이 four_over_six 레시피에서 최적 결과를 보였다.

**Step 2: QAD 학습**

- 시퀀스 길이: 초기 실험은 256K, 최종 학습은 522K(SFT 단계와 유사) 사용, 긴 문맥 벤치마크 성능 보존에 중요했다.
- 데이터: Nemotron-Post-Training v1/v2 데이터셋 활용 권장.
- 학습률 5e-6(고정, warmup 없음), dropout 비활성화, gradient clipping 1.0, 2노드×8GPU(TP=2, EP=4) 구성.
- 양자화 스케일 처리 방식은 PTQ 캘리브레이션 방법에 따라 두 갈래로 나뉜다.

![동적 스케일 대 고정 스케일 양자화 비교 다이어그램](https://developer-blogs.nvidia.com/wp-content/uploads/2026/08/quantization-scale-handling-qad-dynamic-frozen.webp)
*이미지 출처: [원문](https://developer.nvidia.com/blog/developing-nemotron-3-5-lightning-nvfp4-with-qad-using-nvidia-model-optimizer/)*

- **동적 스케일 QAD**: max 캘리브레이션 PTQ 체크포인트(`max`, `mamba_fp8_max`)에서 시작, 학습 중 스케일을 매 스텝 재계산.
- **고정 스케일 QAD**: MSE 기반 PTQ 체크포인트(`MSE`, `four_over_six` 등)에서 시작, PTQ 때 찾은 스케일을 고정하고 가중치만 업데이트.

**체크포인트 평가 결과**

- Checkpoint A: PTQ만으로 median 정확도 복구율 96.33% → QAD 적용 후 99.72%로 개선, 11개 벤치마크 중 10개 향상 (AIME 2025 +3.13, SciCode Subtask +3.37 등).
- Checkpoint B: PTQ 95.84% → QAD 98.53%, AA v4.1 Index가 20.03→23.48로 상승(BF16 기준 24.81).
- 최종 NVFP4 체크포인트: 보수적으로 양자화되어 PTQ가 이미 BF16에 근접(median 복구율 99.24%), QAD는 98.97%이나 Terminal-Bench v2.1(+3.79점), SWE-Bench Multilingual(+1.07점), HLE(+0.65점) 등 에이전틱·코딩 벤치마크에서 우위를 보임.
- 모든 실험에서 PTQ와 QAD 체크포인트는 동일하게 21.19GB(BF16 65.85GB 대비)로, 정확도 차이는 순수하게 방법론(QAD) 효과다.

**Model Optimizer로 QAD 재현하기**

- 전체 QAD 레시피는 `megatron_lm_qad.yaml` 단일 launcher로 실행 가능하며 Nemotron 3 Nano와 3.5 Lightning 모두에 동일하게 적용된다.
- Step 1(PTQ)에서는 `QUANT_CFG: MAMBA_MOE_NVFP4_CONSERVATIVE_CFG` 등 설정으로 BF16 teacher를 NVFP4 student로 양자화.
- Step 2(증류)에서는 `--export-kd-teacher-load`와 `--modelopt-enabled` 옵션으로 QAD를 활성화, Megatron-LM의 `finetune.sh`가 실제 증류 루프를 실행.
- Megatron-Bridge를 통한 동일 파이프라인도 지원되며, `mbridge_qad.yaml`은 토크나이즈→양자화→증류→내보내기 4단계를 8노드×4GPU(TP=1, PP=1, CP=4, EP=16) 구성으로 수행(약 200 iteration, 4.19억 토큰).
- 최종 NVFP4 체크포인트는 Hugging Face에 공개되어 있다.

**대상 독자**: 대형 언어모델을 엣지·저메모리 환경에 배포하려는 ML 엔지니어, 그리고 양자화로 인한 정확도 손실을 최소화하면서 추론 속도를 높이고 싶은 인프라/최적화 담당자에게 유용하다.
