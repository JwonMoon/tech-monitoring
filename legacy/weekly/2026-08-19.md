# 주간 하이라이트 — 2026-08-12 ~ 2026-08-18

이번 주 NVIDIA 블로그는 "에이전틱 AI를 어떻게 더 빠르고 저렴하게 실행할 것인가"에 초점이 맞춰져 있다. Nemotron 계열의 경량·대형 모델 동시 출시, 작업별로 모델을 자동 분배하는 라우팅 인프라, 그리고 GB300 NVL72에서의 실측 성능 벤치마크가 한 축을 이루며, 초대형 오픈 모델의 Day-0 서빙 지원이 다른 한 축을 이룬다.

#### 1. [NVIDIA Nemotron 3 Ultra Powers Faster, More Efficient Reasoning for Long-Running Agents](https://developer.nvidia.com/blog/nvidia-nemotron-3-ultra-powers-faster-more-efficient-reasoning-for-long-running-agents/)

- 550B 파라미터(활성 55B) MoE 오픈 모델로, 장시간 실행되는 멀티 에이전트 워크플로우의 오케스트레이션·복잡 추론에 최적화되었으며 동급 오픈 모델 대비 5배 높은 추론 처리량을 기록
- SWE-bench·Terminal-bench 2.0 등에서 더 적은 토큰으로 작업을 완료해 비용을 최대 30% 절감, 하이브리드 Mamba-Transformer·NVFP4·MTP와 신규 학습 기법 Multi-Teacher On-Policy Distillation(MOPD)을 도입
- 가중치·데이터·레시피가 OpenMDW-1.1 라이선스로 공개돼 LoRA/SFT/RL 파인튜닝이 가능하고, NemoClaw·OpenShell을 통해 안전한 에이전트 실행 환경까지 함께 제공

#### 2. [Route AI Agent Workloads Across Models with NVIDIA NeMo Switchyard](https://developer.nvidia.com/blog/route-ai-agent-workloads-across-models-with-nvidia-nemo-switchyard/)

- 모든 요청에 프론티어 모델을 쓰는 대신, 작업 단계별로 가장 적합한 모델(대형/소형, 오픈/폐쇄)에 자동 라우팅하는 오픈소스 시스템으로, LangChain 벤치마크에서 프론티어 모델 대비 비용 74% 절감(호출 비중 7%)을 달성
- 튜닝 없이 쓰는 LLM classifier·stage router·escalation router와, 내부 상태(residual stream)를 학습해 최적 트레이드오프를 찾는 튜닝형 prefill router를 모두 지원
- Cognition의 Devin Desktop 사례에서는 Opus 5 대비 정확도 2.8%p 차이로 평균 비용 약 28% 절감, OpenAI/Anthropic/Responses API 포맷을 지원하는 게이트웨이 형태로 기존 인프라에 통합하기 쉬움

#### 3. [NVIDIA Achieves Leading Agentic Coding Performance on First Agentic AI Benchmark](https://developer.nvidia.com/blog/nvidia-achieves-leading-agentic-coding-performance-on-first-agentic-ai-benchmark/)

- Artificial Analysis가 만든 업계 최초 멀티벤더 에이전트 벤치마크 AA-AgentPerf에서, NVIDIA GB300 NVL72가 이전 세대 H200 대비 메가와트당 최대 20배 많은 동시 에이전트를 지원
- 실제 코드 저장소 이슈 해결·12개 이상 언어·프론티어 모델 응답 기반 사전 녹화 트래젝토리로 비결정적 LLM/툴 호출 패턴을 재현해 신뢰성 있는 비교 지표 제공
- NVLink 스케일업 도메인, WideEP/DeepEP MoE 분산 최적화, DeepGEMM·NVFP4 커널 등 하드웨어-소프트웨어 공동 설계가 성능의 핵심 동력

#### 4. [Serve Qwen3.8-2.4T-A95B, a 2.4T-Parameter Model, with Configurable Reasoning on NVIDIA GB300 NVL72](https://developer.nvidia.com/blog/serve-qwen3-8-2-4t-a95b-a-2-4t-parameter-model-with-configurable-reasoning-on-nvidia-gb300-nvl72/)

- Alibaba가 공개한 최대 규모 오픈 웨이트 모델(총 2.4T, 활성 95B)을 추가 튜닝 없이 GB300 NVL72(FP8)에서 Day 0에 GPU당 초당 4천 토큰 이상, 사용자당 초당 350 토큰 이상으로 서빙
- 파인그레인드 MoE와 풀·선형 어텐션 하이브리드 구조로 최대 100만 토큰 컨텍스트에서도 연산·메모리를 억제, 요청 단위 low/high/xhigh 추론 강도 조절 지원
- SGLang·vLLM·NVIDIA Dynamo·NIM으로 배포 가능하고 NeMo AutoModel로 Hugging Face 체크포인트를 변환 없이 바로 파인튜닝 가능

#### 5. [NVIDIA Nemotron 3.5 Lightning Delivers Fast, Accurate Specialized Task Execution for Long-Running Agents](https://developer.nvidia.com/blog/nvidia-nemotron-3-5-lightning-delivers-fast-accurate-specialized-task-execution-for-long-running-agents/)

- 3B 활성 파라미터의 30B급 경량 MoE 오픈 모델로, 상시 작동 에이전트의 고빈도 실행 작업(도구 호출·검증·서브에이전트 위임)에 특화되어 유사 크기 모델 대비 최대 4배 빠른 출력 속도 기록
- Nemotron 3 Ultra 같은 대형 모델이 오케스트레이션을, Lightning이 고빈도 실행을 맡는 "모델 시스템" 구조를 지향하며 NeMo Switchyard로 라우팅 대상에 통합
- DGX Spark·Jetson·GeForce RTX 5090 등 로컬 환경부터 데이터센터까지 동일 NVFP4 체크포인트로 배포 가능해 온디바이스 에이전틱 AI 진입 장벽을 낮춤
